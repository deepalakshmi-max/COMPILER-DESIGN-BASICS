LEXICAL ANALYZER – TASK DESCRIPTION

The objective of this task is to build a simple lexical analyzer program that reads data from an input file and identifies keywords, operators, and identifiers. A lexical analyzer is the first phase of a compiler and is used to break source code into meaningful tokens.

In this program, an input file containing source code is provided. The program reads the file character by character or word by word. It then checks each token and classifies it as a keyword, operator, or identifier based on predefined rules. Common programming keywords and operators are identified, while valid variable names are recognized as identifiers.

The program displays the identified tokens along with their types as output. Sample input and output are included to demonstrate how lexical analysis works. The code is written in a simple and modular manner so that it is easy to understand and modify.

This task helps students understand the basic working of compilers and the role of lexical analysis in programming languages. It also improves knowledge of string handling and file processing in programming.
